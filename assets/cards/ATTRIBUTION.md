# Card image attribution

The card images in this directory were taken from https://code.google.com/archive/p/vector-playing-cards/

They were copied from CapersBot (https://github.com/tznkai/CapersBot, `cardimages/`), which used the same source.

Selection used by Green Oaks Bot (40 cards: A, 2–7, J, Q, K in four suits):

- Aces: `ace_of_<suit>.png` (the plain `ace_of_spades.png`, not `ace_of_spades2.png`)
- 2–7: `<n>_of_<suit>.png`
- Jacks: `jack_of_<suit>.png` (plain art)
- Queens and Kings: `queen_of_<suit>2.png`, `king_of_<suit>2.png` (alternate art)

This matches the files CapersBot actually loads.
